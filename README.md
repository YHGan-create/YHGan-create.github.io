# Y.H. Gan Laboratory — GitHub Pages website

A static, mobile-responsive academic laboratory website. No Wix, paid hosting, framework, build pipeline, or account keys required.

## Deploy
1. Create a **public** GitHub repository named `YOURUSERNAME.github.io` (replace YOURUSERNAME with your actual GitHub username).
2. Upload **the contents of this folder** to the repository root, including `index.html`, the other HTML pages, `assets/`, and `.nojekyll`.
3. Go to **Settings → Pages → Build and deployment**. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`, and Save.
4. Wait a few minutes and visit `https://YOURUSERNAME.github.io/`.
5. For a project repository instead, name it e.g. `gyhlab` and access `https://YOURUSERNAME.github.io/gyhlab/`. All internal links are relative and support either deployment.

## Editing
- Edit page text directly in its `.html` file using GitHub's pencil icon, then commit.
- Change design colours and typography in `assets/style.css`.
- Add original scientific figures named `assets/figure-1.jpg` through `assets/figure-4.jpg`.
- Add original gallery images after checking ownership and permission.
- `assets/publications.json` is an editable publication reference dataset; the visible bibliography is currently in `publications.html`.
